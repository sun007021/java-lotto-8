# java-lotto-precourse
## 로또
- [x] 로또 번호가 6개의 숫자로 이루어 졌는지 검증
- [x] 로또의 각 번호가 1~45 사이의 정수인지 검증

## 로또 게임
- [ ] 로또 구매
    - [ ] 금액이 1000원 단위의 자연수가 맞는지 검증
    - [ ] 1000원당 1개의 로또 생성
        - [ ] 중복되지 않은 6개의 랜덤 숫자 생성해 로또 생성(1~45사이)
- [ ] 당첨 번호와 보너스 번호가 1~45 사이의 정수인지 검증
- [ ] 당첨 검사
    - [ ] 구매한 로또들과 당첨 번호 비교해 등수 계산
    - [ ] 등수별 상금 매핑
- [ ] 수익률 계산

## 입력
- [x] 로또 구입 금액 입력
    - [ ] 숫자뒤 단위 파싱해 제거
    - [ ] 구입금액 정수로 변환
    - [ ] 정수 오버플로우 검증
- [x] 로또 번호 6개 입력
    - [ ] 쉼표(,) 기준으로 구분
        - [ ] ,뒤에 공백이 있으면 제거
    - [ ] 파싱 불가할 경우 예외 처리
    - [ ] 구분된 숫자들 정수인지 검증
    - [ ] 숫자들 정수 리스트로 변환
- [x] 보너스 번호 입력
    -[ ] 검증 후 정수로 변환 

## 출력
- [ ] 구매한 개수 출력
- [ ] 생성된 로또 번호들 출력
- [ ] 당첨 통계 출력
- [ ] 총 수익률 소수점 둘째 자리에서 반올림 해 출력
- [ ] 각 예외 처리시 [ERROR]로 시작하는 에러 문구 출력
